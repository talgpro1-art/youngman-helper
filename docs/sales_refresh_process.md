# 판매순위 갱신 프로세스

## 범위와 입력

- 공개 월간 국산 판매·수입 등록 모델별 표를 각각 확인한다. 빈 표는 0대나 새 집계로 취급하지 않는다.
- 전체 원천 모델을 확인하고 기록한다. 현재 `source_rows_2026-11-03.json`에는 국산 69개·수입 155개, 총 224개 모델이 있다.
- `reviewed_sales.csv`에는 국산 69개와 검증된 수입 13개를 보관한다. 미보관 수입 모델의 최대 판매대수 447대가 TOP50 경계 556대보다 낮음을 전체 원천으로 검증했다.
- 필수 컬럼: `brand`, `model`, `units_sold`, `source_period`. 수입 행의 `source_model_url`로 원천 세대를 구분한다.
- 임의 차종 합산 금지: E-Class Model=4516은 2,748대, 구형 Model=3757은 1대이며 서로 다른 행이다. 원천이 분리한 내연기관·전기차와 신·구형도 합치지 않는다.

## 갱신 순서

1. 최신 main과 원천을 비교한다. 값·기준월·TOP50에 변화가 없으면 파일·확인일·순위변동을 다시 쓰지 않는다.
2. 원천 증빙과 `reviewed_sales.csv`를 갱신한다. 판매대수 내림차순, 동률은 국산 우선·시장 내 원천 순서로 정렬한다. 50위와 51위가 동률이면 반영을 보류한다.
3. 새 진입 차량은 공식 모델/세대·가격/자료·이미지를 확인하여 `vehicle_updates_<확인일>.json`과 이미지 검증 내역을 준비한다. 기존 차량의 비순위 필드는 그대로 보존한다.
4. 빌더의 `UPDATE_ID`, `BASELINE`, `VEHICLE_UPDATES`, `SOURCE_ROWS`를 새 검증본에 맞춘다. `BASELINE`은 실행 직전 실제 배포 master를 최초 한 번만 보관하며 재실행 시 변경하지 않는다.
5. 아래 빌드·회귀·앱 검사를 실행한다. 순위변동은 보관한 직전 반영본 대비이며 NEW는 직전 TOP50 밖의 차량이다. 같은 입력 재실행은 바이트·수정시간·순위변동을 유지한다.
6. 변경 범위와 최신 원격 main을 재검토한 뒤 승인된 갱신 파일만 한 커밋으로 반영한다. 병행 변경은 보존하고 강제 푸시는 사용하지 않는다. 해당 커밋의 검사와 실제 앱을 확인한다.

```sh
python scripts/build_combined_sales_rankings.py
python scripts/test_sales_refresh.py
python scripts/test_app_sales.py
python -m compileall -q app.py scripts
```

기존 `update_sales_rankings.py`는 신규 진입·최신 기준월·누락 행 및 재실행 보존을 이 절차처럼 검증하지 않으므로 이 월간 통합 TOP50 갱신에는 사용하지 않는다. 뉴스·가격 링크 정기 워크플로는 판매순위 갱신과 별개이며, 순위 변경을 이유로 전체 가격·이미지를 재수집하지 않는다.

## 현재 반영본

2026-11-03(KST) 확인: 국산 2026-10·수입 2026-09, 국산 41개·수입 9개. 트랙스 크로스오버 556대가 50위, BMW 3 Series 527대가 51위다. 10월 수입 표가 비어 있어 검증된 9월 155개 원천 행을 그대로 유지했다. 직전 실제 배포 TOP50(국산·수입 9월)의 스냅샷을 최초 한 번 보관하고 순위변동을 계산한다. `source_period`와 앱의 혼합월 안내를 유지한다.

신규/재진입은 디 올 뉴 투싼(Model=4757, 5세대), 베뉴(Model=3654), EV6(Model=4641)이다. 구형 투싼(Model=4592)과 합치거나 구형 자료·이미지를 재사용하지 않는다. 계속 포함되는 47개 모델의 비순위 메타데이터는 모두 그대로 보존한다. 기아 버스/특수 229대는 통합 77위로 이번 TOP50 밖이며, 기존 메타데이터 문제가 전역적으로 해결되었다는 의미는 아니다.

## 2026-11-03 별도 가격 링크 검수 (로컬 제안)

판매순위 전용 커밋 `761d91c00c457327ff17137d3c305a9dcbb94768`은 보존한다. 그 순위 반영본을 기준으로 `price_audit_2026-11-03.json`에 전체 후보 50개와 배포본에만 남은 3개, 총 53개 모델·95개 링크 필드의 공식 근거와 확인시각을 기록했다. 공식 최신 연결 대상 확인과 문서 본문/세대 확인은 구분하며, 게시판 로드맵·알림의 별도 링크는 이 검수에 포함하지 않는다.

후보 50개는 검수 전 최신 연결 34개·구판 연결 9개·불확실 7개였다. 링크 필드 기준 최신 67개·구판 12개·불확실 11개이며, 고장으로 확정한 링크는 없다. 본문까지 확인한 쏘나타, BMW 5 Series/X3, 그랑 콜레오스, 트랙스의 가격표 5개만 교체한다. 해당 5개 모델, 기아 봉고 3/레이 EV, 제네시스 G80/GV80/GV70의 설명 10개만 직접 근거에 따라 수정한다. 제네시스는 11월 게시 목록 확인이며 PDF 본문 검증 완료를 의미하지 않는다.

벤츠 2개 가격표와 르노 5개 문서 링크는 공식 새 대상은 확인했지만 본문 검증이 부족하여 기존 링크를 유지한다. 불확실 7개 모델도 그대로 유지하며 배포본에만 남은 구형 투싼/BMW 3 Series/X5는 검수 기록만 남긴다. 제한적 수정 후 후보는 최신 38개·일부 구판 5개·불확실 7개다. 전체 최신화 완료로 보고하지 않는다.

`history/vehicle_master_before_2026-11-03-price-audit.csv`는 가격 검수 전 순위 반영본을 그대로 보관한다. 가격 변경은 아래 독립 단계로 적용하며, 원래 값이 바뀌었거나 미검증 교체이면 쓰기 전에 중단한다. 다시 실행해도 파일 내용과 수정시간은 변하지 않는다. 순위 빌더의 계속 포함된 차량 메타데이터 보존 원칙은 유지한다.

```sh
python scripts/build_combined_sales_rankings.py
python scripts/apply_reviewed_price_updates.py
python scripts/test_sales_refresh.py
python scripts/test_price_audit_updates.py
python scripts/test_price_audit_display.py
python scripts/test_app_sales.py
```

`data/link_status.csv`와 알림은 일괄 재작성하지 않는다. 앱은 차량명과 정확한 현재 가격 URL이 모두 같은 기존 검수만 표시하고, 차종명 일치를 세대/연식 검증으로 표현하지 않는다. 수정된 커밋은 별도 명시 승인을 받기 전 원격 main에 게시하지 않는다.
